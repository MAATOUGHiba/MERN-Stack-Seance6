# MERN Stack - Séance 6

## Gestion d'état global avec React

Ce projet a été réalisé dans le cadre de la séance 6 du cours MERN Stack.

### Objectifs
- Utiliser `useContext` pour gérer le thème clair et sombre.
- Utiliser Redux Toolkit pour gérer le panier.
- Partager les données entre les composants.
- Sauvegarder les données dans `localStorage`.

### Technologies utilisées
- React
- Vite
- Redux Toolkit
- React Redux
- JavaScript
- CSS

### Installation

```bash
npm install
```

### Lancer le projet

```bash
npm run dev
```

### Fonctionnalités
- Changer entre le thème clair et sombre.
- Ajouter et supprimer des produits du panier.
- Afficher le nombre de produits et le prix total.
- Garder le panier après le rechargement de la page.
